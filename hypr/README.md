# hypr/ — Hyprland 0.56.2 Lua config

Native Lua port of the Caelestia hyprlang tree (`~/.local/share/caelestia/hypr` + `~/.config/caelestia/hypr-*.conf`)
with the helper scripts moved in-process. API reference: `docs/dev/design-lua.md`, `/usr/share/hypr/stubs/hl.meta.lua`.

```
Hyprland --verify-config -c /home/lpacheco/Projects/Quantum-Moon/hypr/hyprland.lua   # must print "config ok"
```

inhibit and locked-sleep scripts also write the legacy `caelestia-*` names the live Caelestia shell reads
(`patches/quickshell-caelestia/modules/IdleMonitors.qml`) until the cutover.

## Switch / rollback

Hyprland chooses its config manager (hyprlang or Lua) **once, at startup**. A running hyprlang session
that is pointed at this directory and told to `hyprctl reload` will not switch: it looks for a
`hyprland.conf` at the new path, finds none, and autogenerates a stub (8 emergency binds, no
monitor layout). So the switch is: relink, then **log out and back in**.

```sh
# 1. point the config dir at the repo (keep the current hyprpaper.conf)
cp -L ~/.config/hypr/hyprpaper.conf ~/Projects/Quantum-Moon/hypr/hyprpaper.conf 2>/dev/null
ln -sfn ~/Projects/Quantum-Moon/hypr ~/.config/hypr
# 2. restart Hyprland (log out / log in). From then on `hyprctl reload` reloads the Lua config.

# rollback (also needs a restart to go back to the hyprlang manager)
ln -sfn ~/.local/share/caelestia/hypr ~/.config/hypr
```

If you already reloaded by mistake and the session has only the emergency binds: relink the old
directory and `hyprctl reload` (the hyprlang manager is still active, so that restores it instantly),
or just log out and in with the repo symlink in place. Delete any autogenerated `hypr/hyprland.conf`
stub afterwards.

## Live checks after the switch

- bind count: `hyprctl binds -j | jq length` ~ 203 (baseline 293 minus the 121 generated interrupts, the
  unbinds and the two clash resolutions; `features/launcher_super.lua` adds 44 fallback key interrupts +
  8 mouse interrupts, so ~159 once `fallback_interrupts = false`). Submaps: `mousedragthumb` 3 binds, `mouse5group` 2.
- `hyprctl monitors -j` geometry unchanged; `hyprctl getoption decoration:shadow:color` reflects the scheme.
- Super tap opens the launcher, a Super chord (Super+T, Super+1, Super+mouse) does not. In `hyprctl repl`
  check that `input.keyboard.key` fires for a bound key; if it does, set `QM.features.launcher.fallback_interrupts = false`
  in `local.lua`.
- Alt+Tab / Shift+Alt+Tab cycle in display-line order, including tabs hidden in a group.
- Thumb buttons: mouse4 + LMB/RMB drag moves/resizes, mouse5 + LMB click groups/ungroups, both inert in a Steam game.
- Scratchpad: Super+Alt+S / Ctrl+Super+S / Ctrl+Super+Space moves the window to `special:special` and back.
- Hotplug: unplug DP-2 -> packed layout, bar on the rightmost, toast, `qm-apply --persisted`; replug -> defaults.
  (Phase 1: `caelestia-main-monitor-hotplug.service` still runs the old script in parallel; disable it in Phase 3.)
- Game mode: Steam game fullscreen -> `$XDG_RUNTIME_DIR/quantum-moon-game-mode.active`, mpvpaper paused; exit resumes.
- Telegram: open/close the media viewer, the chat window must not stay fullscreen.
- `qm-apply <slug>` recolours borders/groupbar/shadow and (once hyprsunset is installed) changes the night temperature;
  `hyprctl repl 'return QM.scheme.night_temperature'`.
- Clash resolutions: Ctrl+Super+Space = scratchpad only, Super+Shift+M = qm-random only.
