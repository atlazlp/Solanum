# The Hyprland Lua config

Hyprland 0.55+ reads `~/.config/hypr/hyprland.lua` (a symlink to `hypr/` in this repo). Everything is plain Lua on the `hl.*` API; the autogenerated stubs at `/usr/share/hypr/stubs/hl.meta.lua` give completion when `.luarc.json` points at them.

## Structure

`hyprland.lua` requires, in order: `lib/util` (the `QM` global: paths, helpers), `lib/shell` (how binds talk to the shell), `lib/scheme` (colours from `~/.local/state/quantum-moon/scheme.lua`), then `env`, `monitors`, `general`, `decoration`, `animations`, `input`, `group`, `workspaces`, `rules`, `binds/init`, every `features/*` module inside `pcall` (a broken feature only produces a notification), `autostart`, and finally `local.lua` if present. See `hypr/README.md` for the file-by-file map.

## Rules that keep it working

- Never call `hl.exec_cmd` or `hl.timer` at file top level: a reload re-evaluates the whole config, so top-level execs run again, and both calls crash `Hyprland --verify-config`. One-shots go in `hl.on("hyprland.start", ...)`, repeating timers through `QM.util.on_live(fn)` (runs on start and after every reload, which clears timers).
- Callbacks have budgets (events 50 ms, binds 100 ms, timers 50 ms). Spawn processes with `hl.exec_cmd`; never block.
- `require` adds the file to the reload watch set; `dofile` does not. `lib/scheme.lua` therefore uses `dofile` on the engine-written `scheme.lua` and `qm-apply` triggers one explicit `hyprctl reload`.
- `hl.get_windows{class=...}` matches exactly (no regex). Window rules use regex strings with doubled backslashes.
- Release binds are matched against the submap active at press; the thumb-button release binds use `submap_universal`.
- `size`/`move` rule values are muParser expressions over `monitor_w monitor_h window_w window_h`; the old `%` shorthands are gone.

## Verify and reload

```sh
./scripts/hypr-verify.sh            # verify-config + script syntax + live summary
hyprctl reload                      # or just save a file: the watcher reloads
hyprctl configerrors
hyprctl repl 'return hl.version(), QM.scheme.night_temperature'
```

## Talking to the shell

`lib/shell.lua` is the only file that knows the shell's IPC name. Binds call `hl.dsp.global("qm:<name>")` for global shortcuts and `hl.dsp.exec_cmd(QM.shell.ipc(target, fn, ...))` for IPC. The shell signals Hyprland back with `hyprctl dispatch event qm:<topic>:<payload>`.
